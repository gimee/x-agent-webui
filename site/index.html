01 · MEMORY-FIRST COMPACTION

压缩的是噪声，不是你的要求。Compress the noise, not your intent.

普通的上下文压缩会把长对话"总结掉"，你早先定下的约束也一起消失。X-Agent 把用户意图当成最高优先级的上下文来保护。

Ordinary context compression summarises a long conversation away — and the constraints you set early on vanish with it. X-Agent treats your intent as the context that must survive.

Claude记忆优先Memory-first

  • 约 40 万 token 触发，你的每一句原话逐字跨代保留
  • Triggers at about 400K tokens; every message you wrote is carried forward verbatim
  • 摘要分节撰写，附只读原文档案，模型需要时可回查
  • Sectioned summary plus a read-only transcript archive the model can consult
  • 剩余预算再放最近原文，大工具输出只留头尾
  • Remaining budget keeps recent turns; huge tool output keeps only head and tail

Hermes按你的规则执行Your rules, enforced

  • 严格遵循目标比例、保护最近与开头消息等压缩设置
  • Honours target ratio and protected recent/opening messages exactly
  • 触发点按真实调用用量校准，不再压缩得太晚
  • Trigger calibrated against real usage, so compaction is never too late
  • 超长历史分块总结，每块不超过 12 万 token
  • Very long histories are summarised in chunks of at most 120K tokens

Both失败也不丢历史Failure never costs history

摘要失败、超时或返回错误提示时一律保留原文——历史绝不会被一句错误替换。压缩进度在对话里实时可见，完成后上下文数字立即刷新。

A failed, timed-out or error-shaped summary is discarded and the original kept — history is never replaced by an error string. Progress shows in the chat, and the context meter refreshes the moment it finishes.

summary error    → keep original
summary timeout  → keep original
summary ok       → 412K → 81K

辅助模型写摘要，更快Faster with an auxiliary model

一段约 45 万 token 的对话，生成摘要所需时间：

Summarising a conversation of about 450K tokens:

原生Native~5 min
辅助模型Auxiliary~2.5 min
增量压缩Incremental~40 s

发送给辅助模型前先脱敏；辅助模型不可用时自动退回由 Claude 自己写。

Content is redacted before it reaches the auxiliary model; if that model is unavailable, Claude writes the summary itself.

02 · BUILT FOR THE LONG RUN

每个细节，都为长时间工作而改。Every detail, reworked for long sessions.

消息零重复、零丢失No duplicated or lost messages

每条消息带稳定身份，贯穿发送、排队、多端广播、断线恢复与落库。刷新、重连、重启后不重复不丢失，不会一直卡在「工作中」，中止前已流出的输出也会保存。

A stable identity follows every message through sending, queueing, multi-tab broadcast, reconnect recovery and storage. Refreshes, reconnects and restarts neither duplicate nor drop anything, runs never hang on "working", and output streamed before an abort is kept.

三个 Agent，一个工作台Three agents, one workspace

Hermes Agent、Claude、Pi 共用同一界面与会话体验。推理强度可按对话单独设置（低到 Max）并真实生效，上下文用量显示准确，对话自动起标题。

Hermes Agent, Claude and Pi share one interface and one session model. Per-conversation reasoning effort (Low to Max) really takes effect, context meters are accurate, and conversations title themselves.

记忆由你掌控Memory you control

记忆锁：不解锁，Agent 就无法写入你的 MEMORY.md / USER.md，切换即时生效。整理好的笔记可一键同步给 Claude。

The memory lock keeps agents from writing your MEMORY.md / USER.md until you unlock it, effective immediately. Curated notes sync to Claude in one click.

稳定，不折腾Stable by design

界面冻结，不随上游频繁改版；每次升级只更新 Hermes Agent、Claude Code、Pi 三个 Agent 层。群聊、工作流等冗余功能已移除，专注对话本身。

The interface is frozen instead of churning with upstream redesigns; upgrades only refresh the Hermes Agent, Claude Code and Pi layers. Group chat, workflows and other extras are gone — the focus is the conversation.
